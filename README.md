# LosslessPipeline

Десктопное приложение на Python (PySide6) для автоматизированного управления музыкальной коллекцией в lossless форматах, пакетной нормализации тегов, поиска синхронизированных текстов (Synced Lyrics) и аудита качества аудио.

## Основные возможности

* **Импорт и структурирование**: Группировка релизов по папкам и тегам, предотвращающая смешивание разных альбомов.
* **Умный поиск метаданных**: Интеграция с Apple Music/iTunes, Deezer и MusicBrainz для получения эталонных треклистов и обложек в высоком разрешении.
* **Вшивание Synced Lyrics**: Автоматический поиск таймкодов на LRCLIB и вшивание их внутрь файлов FLAC.
* **Аудио-аудит (FFT)**: Спектральный анализ для выявления поддельных FLAC-транскодов из MP3.
* **Встроенный аудиоплеер**: Плеер с показом караоке-строк в реальном времени, звуковой волной (Waveform) и поддержкой режима Shuffle.

## Стек технологий

* **Python 3.10+**
* **PySide6** (Qt 6)
* **Mutagen** (работа с тегами FLAC)
* **SoundFile & NumPy** (анализ спектра и генерация волны)
* **Httpx** (асинхронные сетевые запросы к API)
